Comment installer le fichier ?
  1. Touchez le bouton vert et attendez la fin du téléchargement.
  2. Ouvrez le fichier telima.apk depuis la notification ou « Téléchargements ».
  3. Si Android le demande, autorisez « Installer des applications inconnues » pour votre navigateur.
  4. Touchez « Installer », puis ouvrez Telima.

Sans téléchargement

Ajoutez Telima à votre écran d'accueil : elle s'ouvre en plein écran, comme une application.

  1. Ouvrez cette page dans Safari.
  2. Touchez le bouton Partager (carré avec une flèche).
  3. Choisissez « Sur l'écran d'accueil », puis « Ajouter ».
  1. Ouvrez cette page dans Google Chrome.
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
